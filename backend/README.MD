# 📚 SoulSpace - Smart Library Management System

SoulSpace is a modern full-stack Library Management System designed to provide students with a smart, interactive, and productive library experience.

Unlike traditional library systems that only manage books, SoulSpace integrates book discovery, seat reservation, study lounges, library events, and personalized user dashboards into a single platform.

---

- Browse all books

- Search books by author
- Search books by category
- Book details page
- Book availability
